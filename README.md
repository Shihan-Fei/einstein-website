# Albert Einstein's Personal Website

## Project Description
This project is a personal website for Albert Einstein. It introduces his publications, hobbies, and interests.

## Website Features
- About Me
- Publications
- Hobbies
- Image Gallery
- Blog

## Technologies Used
- HTML
- CSS
- JavaScript

## Responsive Design
The website supports both desktop and mobile layouts. A media query is used to adjust the layout for screens that are 500px wide or smaller.
